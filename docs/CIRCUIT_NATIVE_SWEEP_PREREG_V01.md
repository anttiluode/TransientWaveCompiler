# TW-1A circuit-native emulator / sweep preregistration v0.1

Status: **frozen before circuit-native learning results are inspected**.

This experiment replaces the old abstract `mirror_error` and independent `PLUS/MINUS pass drift` knobs with errors generated by the proposed `tw1a-sc-lockstep-v0.2` circuit.

## Question

Does the lockstep circuit architecture turn the previously severe long-pass coherence requirement into tolerances on local adjacent-subphase primitives that are plausibly calibratable/measurable?

The experiment is allowed to fail. A failure is retained rather than tuning a threshold after seeing it.

## Reference digital / mixed-signal structure

- 8x8 / 64 node / 112 four-neighbor tile.
- one signed exact-zero reciprocal rank-one edge cell per bond;
- 8-bit edge coefficient path, +/-0.25 nominal range;
- 12-bit node self path, +/-3.0 range;
- 8-bit drive DAC;
- 10-bit returned-error DAC;
- 8-bit sense ADC with one frozen binary PGA;
- exact current/previous pointer-swap mirror;
- two reverse state contexts `F+A` and `F-A`;
- one held physical coefficient realization from the objective forward pass through its lockstep reverse pair;
- one shared signed local credit accumulator.

The legacy emulator variables `mirror_error` and `differential_pass_drift` are fixed to zero and are invalid inputs to this emulator.

## Circuit-native error variables

The v0.1 circuit emulator must expose these independently:

1. `edge_gain_cv`: fixed post-programming edge-MDAC gain mismatch, common to forward and both reverse lanes.
2. `self_gain_cv`: fixed self-MDAC gain mismatch, common to forward and both reverse lanes.
3. `terminal_clone_gain_std`: fixed node/bank gain mismatch when terminal lane A is copied once into lane B.
4. `edge_settling_error`: fractional lane-B edge transfer deficit because the shared edge MDAC is observed in the later subphase.
5. `ab_edge_memory`: residual fraction of lane-A edge transfer appearing in lane B from incomplete reset/settling.
6. `edge_charge_injection_std`: fixed lane-select-dependent edge charge injection, expressed as RMS fraction of state full scale per active edge/tick.
7. `prev_ratio_error_std`: fixed node-wise error of the nominal unity `-PREV` switched-capacitor ratio, shared by lanes.
8. `error_dac_sign_asymmetry`: differential magnitude error between `+error` and `-error` routing from one error-DAC sample.
9. `lcc_curvature`: quartic correction of the shared square-law detector, normalized so `1.0` is order-unity curvature only near the maximum representable edge difference.
10. `credit_accumulator_leakage`: exponential signed-credit decay rate per wave tick.

Existing state leakage, state noise, final credit readout noise and final credit offset remain available but are not swept in the first circuit-native isolation experiment; they already have prior emulator evidence.

## Exact zero-error audit

With all quantizers disabled and all analog errors zero, lockstep physical credit must match finite differences of the same circuit recurrence.

Pass criteria:

- relative L2 error <= `2e-5` on sampled trainable edges;
- Pearson correlation >= `0.999999`.

If this fails, no hardware sweep result is interpretable.

## Quantized reference learning confirmation

Fresh temporal-order arbors: seeds **1100-1104**.

Training:

- 30 updates;
- normalized host update;
- step size 0.20;
- same measured credit sent to a fixed norm-matched shuffled-edge control.

Reference point has 8/12/8/10/8 edge/self/drive/error/sense precision and all circuit-native error variables zero.

Reference PASS requires all of:

1. 5/5 placed-credit learners improve normalized AB-vs-BA contrast by >= `+0.10`;
2. 5/5 placed-credit final contrasts exceed their shuffled-credit controls;
3. median placed-minus-shuffled improvement gap >= `+0.25`.

Failure is retained and the sweeps stop.

### Qualification predicate at each grid value

A value qualifies only if all are true:

- at least 4/5 placed-credit learners improve by >= `+0.10`;
- median placed-credit improvement >= `+0.20`;
- at least 4/5 placed final contrasts exceed shuffled final contrasts;
- median placement gap > 0.

The **measured boundary** is the largest tested value before the first failed grid value, if qualification is monotone. If behavior is nonmonotone, report the entire observed pattern and do not summarize it as a single tolerance.

The **recommended design point** is one grid step inward from the measured boundary. This is an engineering margin convention, not a statistical confidence interval.

## Combination test comes later

Independent one-axis boundaries are not a Cartesian safe box. After the first sweep, a simultaneous corner may be preregistered using inward values. It must use untouched bodies and must not be tuned on the sweep seeds.

## Kill conditions for the circuit architecture

The lockstep circuit direction is materially weakened if any of the following occurs:

- the zero-error lockstep credit does not recover the exact physical gradient;
- adjacent-subphase edge settling/memory must be held at the same ~10-ppm scale as the killed long-pass architecture;
- practical terminal cloning requires reconstructing the complete internal trajectory;
- the shared LCC needs curvature/retention far beyond plausible calibration merely to outperform shuffled credit;
- common static edge mismatch is unexpectedly as damaging as differential subphase mismatch, undermining the intended coherence argument.

No transistor/process feasibility claim is made by this preregistration. The output is a target envelope for SPICE/board work.
